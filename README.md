# Smart Hub

A modern, accessible, and user-friendly platform built with a comprehensive design system.

## 📚 Design System

The Smart Hub Design System provides a complete set of guidelines, components, and patterns to ensure consistency and quality across the application.

### Quick Links

- **[Design System Documentation](./docs/design-system/README.md)** - Complete design system overview
- **[Design Tokens](./docs/design-system/tokens/design-tokens.md)** - Colors, typography, spacing, and more
- **[Components](./docs/design-system/components/)** - Button, Input, Select, Modal specifications
- **[Accessibility Guidelines](./docs/design-system/guidelines/accessibility.md)** - WCAG 2.1 AA compliance
- **[Usage Patterns](./docs/design-system/guidelines/component-patterns.md)** - Common patterns and examples

## 🎨 Core Components

The design system includes specifications for:

- **Button** - Interactive button component with multiple variants
- **Input** - Text input and form field component
- **Select** - Dropdown selection component
- **Modal** - Dialog and overlay component

Each component is documented with:
- Visual specifications and states
- Required and optional props
- Accessibility requirements (WCAG 2.1 AA)
- Usage examples and best practices
- Dos and don'ts

## 🚀 Getting Started

### For Designers
1. Review the [Design Tokens](./docs/design-system/tokens/design-tokens.md)
2. Study the [Component Specifications](./docs/design-system/components/)
3. Follow the [Accessibility Guidelines](./docs/design-system/guidelines/accessibility.md)

### For Developers
1. Reference [Design Tokens](./docs/design-system/tokens/design-tokens.md) in your code
2. Implement components according to [specifications](./docs/design-system/components/)
3. Test for [accessibility compliance](./docs/design-system/guidelines/accessibility.md)
4. Follow [usage patterns](./docs/design-system/guidelines/component-patterns.md)

## ✨ Key Features

- **Accessibility First**: All components meet WCAG 2.1 Level AA standards
- **Consistent Design**: Unified visual language through design tokens
- **Comprehensive Documentation**: Detailed specs with examples
- **Best Practices**: Established patterns for common use cases
- **Responsive**: Mobile-first design approach
